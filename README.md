# Daksha Systems — installers

Downloads and automatic updates for the Daksha Systems billing software.
This repository holds installers only; the source code is private.

Latest version: https://github.com/airrakeshkumarsharma/daksha-systems-releases/releases/latest

| Computer | File |
|---|---|
| Mac (Apple Silicon or Intel) | `Daksha-Systems-<version>-mac-universal.dmg` |
| Windows laptop | `Daksha-Systems-Setup-<version>.exe` |
| Windows pen drive | `DakshaSystems-PenDrive-<version>-win.zip` |
